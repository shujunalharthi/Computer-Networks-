# Question 2: Giving Connections in the LAN

![LAN 1 and LAN 2 Connections](LAN1_LAN2_Connections.png)

## Description & Connection Details
The end devices in LAN 1 (Computer Lab) and LAN 2 (Admin Office) are connected to Cisco 2960 switches, and each switch is connected to Router 1.

### Cable Types Used:
- *PC to Switch:* Copper Straight-Through cable.
- *Switch to Router:* Copper Straight-Through cable.
